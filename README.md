## ✨ Features

- 🔐 User Authentication (JWT)
- 👥 Project Collaboration System
- 💬 Real-time Chat (Socket.io)
- 📋 Task Management
- 🔔 Notifications (Realtime + Email)
- 📎 File Attachments
- 🏷 Labels & Filters
- 👑 Admin Panel
